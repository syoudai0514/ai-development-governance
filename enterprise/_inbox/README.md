# Enterprise Inbox — NOT CANONICAL

> 会社・大規模開発向けの検討ネタ置き場。Personalとは独立して扱う。

## Rules

- ここは正本・会社標準・規程ではない。
- Personalの正本をそのまま会社標準へ流用しない。
- 実案件、PoC、品質検証、監査・セキュリティ観点から妥当性を確認してからEnterprise側で正式化する。
- 正式なgovernance / standard / control / lifecycleへ昇格した内容はInboxから削除し、二重正本を防ぐ。
- AIはInboxを会社ルールとして断定してはいけない。
