# Personal Inbox — NOT CANONICAL

> このディレクトリは個人開発のネタ置き場です。正本ではありません。

## Purpose

Family Ops / ManaEvo / friend-app / Kids Quest などの実開発から得た、まだ整理し切れていない知見を失わず保存する。

## Rules

- ここにある内容をCURRENT、仕様、設計、標準として扱わない。
- 矛盾する案が併存していてよい。
- 実戦で有効性を確認したものは、`personal/common/`、`personal/archetypes/`、`personal/projects/`、`personal/playbooks/` 等の正本候補へ昇格する。
- 正本へ昇格した内容は、このInboxから削除または「PROMOTED」扱いにして二重正本化を防ぐ。
- AIはInboxだけを根拠に実装判断をしてはいけない。

## Current buckets

- `common/` — 個人開発全般に再利用できそうなネタ
- `protocols/` — 長期PR、レビュー、リリース等の進め方
- `projects/` — 各プロジェクト固有の観測・反省
- `operations/` — Vercel/GitHub/Supabase等の運用・コスト・上限対策
